# Project Rules & Style Guidelines

## 🚫 1. STRICT PROHIBITION: No Mermaid Graphs / Flowcharts
*   **NEVER** generate `mermaid` code blocks (`graph TD`, `graph LR`, `flowchart`, etc.) in lessons, guides, notes, or documentation.
*   **Rationale:** Mermaid diagrams render poorly in dark mode, squash text into unreadable narrow columns, wrap awkwardly on mobile/narrow windows, and create poor contrast for readers.

## 📊 2. MANDATORY ALTERNATIVE: Structured Tables & Comparison Matrices
*   **ALWAYS** use clean, high-contrast, structured **Markdown Tables**, **Comparison Matrices**, and **Card-Style Breakdown Boxes**.
*   Every key concept, hierarchy, classification, or anatomical division must be formatted into clean, labeled table columns with bold headers, icons, and bullet points.

## 🎨 3. Visuals & Illustrations
*   For visual aids and anatomical diagrams, always use dedicated generated image illustrations (`.jpg` / `.png`) embedded via standard markdown image syntax `![Caption](./images/filename.jpg)`.
